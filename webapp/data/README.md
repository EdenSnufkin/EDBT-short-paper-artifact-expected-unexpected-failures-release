# Question files

`demo_questions.json` is a **synthetic** bank (84 arithmetic / algebra questions, 21 difficulty levels) so that the application can be tried. It is generated by `make_demo_questions.py`. The questions used in the study are not distributed.

To run the application on your own questions, set `STUDY_QUESTIONS_PATH` to a JSON file with this format (a list, or an object with a `questions` list):

```json
{"questions": [
  {"id": "1", "question": "Compute $3 \\times 4$.", "difficulty": 0.15,
   "options": ["$10$", "$12$", "$14$", "$7$"], "correct_answer": 1},
  {"id": "2", "question": "Solve $2x = 6$.", "difficulty": 0.3, "answer": "3"}
]}
```

* `id`: unique integer (a string of digits is accepted); logged as `item_id`.
* `difficulty`: estimated difficulty in [0, 1]. The recommender moves between *distinct values* of this field, so use a small number of levels (the study used 21, in steps of 0.05) with several questions per level.
* `options` + `correct_answer` (index of the right option): multiple choice. `options` may also be the Python-list string used by the study files. Without `options`, the question is free text compared with `answer` (numeric comparison when both parse as numbers).
* Text and options may contain LaTeX between `$...$` or `$$...$$`.
* All questions are assigned to one topic (`settings.TOPIC`); the study tracked a single skill.
